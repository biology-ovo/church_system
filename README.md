# 교회 물품 관리

HTML, CSS, JavaScript만으로 만든 간단한 물품 관리 웹페이지입니다. 별도 설치, 서버, 데이터베이스 없이 브라우저에서 바로 사용할 수 있습니다.

## 실행 방법

1. 이 폴더의 `index.html`을 더블 클릭합니다.
2. 또는 터미널에서 `python3 -m http.server 8000`을 실행한 뒤 `http://localhost:8000`을 엽니다.

물품 정보는 현재 사용 중인 브라우저의 `localStorage`에만 저장됩니다. 브라우저 데이터를 삭제하거나 다른 기기·브라우저를 사용하면 기존 데이터가 보이지 않으므로 중요한 운영 데이터의 장기 보관에는 적합하지 않습니다.

## 파일 구조

- `index.html`: 화면의 내용과 입력 양식
- `style.css`: 색상, 배치, 모바일 반응형 디자인
- `script.js`: 물품 등록·수정·삭제, 검색·필터, 브라우저 저장

## 현재 기능

- 물품 등록, 수정, 삭제
- 사진 첨부 및 자동 축소
- 물품명·제조사·모델명·위치 검색
- 카테고리 및 상태 필터
- 보관 위치 입력과 기존 위치 자동 제안
- 모바일 반응형 화면
- 브라우저 `localStorage` 저장

> 서버와 로그인, 데이터베이스 같은 새로운 기술은 필요성을 먼저 설명하고 확인받은 뒤 단계적으로 추가합니다.
